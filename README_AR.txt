مشروع أندرويد: دوري أبطال السحور
================================

ما الذي تم تجهيزه؟
- مشروع Android مبدئي يفتح واجهة دوري أبطال السحور داخل تطبيق أندرويد.
- الواجهة محفوظة داخل app/src/main/assets/index.html.
- اسم التطبيق: دوري أبطال السحور.
- معرف الحزمة: com.dawriabtalalsuhoor.app
- أقل إصدار مدعوم: Android 6.0 (API 23).

مهم جدًا:
هذه نسخة أولية لتغليف واجهة HTML كتطبيق أندرويد. لم يتم إنشاء APK هنا لأن بيئة البناء لا تحتوي على Android SDK أو Gradle.
كما أن هذه النسخة لا تحتوي بعد على قاعدة بيانات سحابية أو تسجيل دخول للمسؤول؛ لذلك لا تضمن أن تعديلات جهاز واحد ستظهر عند بقية الأصدقاء.

طريقة بناء APK:
1) افتح المشروع في Android Studio على جهاز كمبيوتر.
2) انتظر مزامنة Gradle وتنزيل مكونات Android المطلوبة.
3) اختر Build ثم Build Bundle(s) / APK(s) ثم Build APK(s).
4) بعد انتهاء البناء سيظهر ملف APK داخل app/build/outputs/apk/debug/.

إذا أردت تعديل الواجهة، استبدل الملف:
app/src/main/assets/index.html

ملاحظة: لم تتم إضافة مفاتيح أو كلمات مرور أو خدمات خارجية.
